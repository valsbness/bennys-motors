# Benny's Motors — Gestión de Taller

**Desarrollado para Toribio Bustamante, dueño de Benny's Motors en Origen RP.**

Sistema de gestión para las operaciones del taller: servicios, órdenes de trabajo, clientes, personal, ventas, comisiones, gastos, actividad y reportes.

## Reconstrucción del proyecto

Este repositorio es la copia de trabajo de la cuenta `valsbness`. Se conservará la funcionalidad del proyecto original y se configurará una instancia nueva de Supabase. Los datos anteriores (cuentas, contraseñas, empleados, ventas y registros) no se migrarán: el taller comenzará con datos limpios.
